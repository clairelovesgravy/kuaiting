# 快听

浅色薄荷风的桌面直播音频工作台，使用 HTML、CSS 和原生 JavaScript。

本地预览：`python3 -m http.server 4173 --bind 127.0.0.1 --directory dist`

## 当前状态

- 已实现直播间 URL 校验、剪贴板粘贴、收藏增删与本地存储、播放设置、响应式页面。
- Web Audio 本地提示音支持播放、暂停、停止、音量及倍速。试听明确标记为非真实直播。
- 淘宝直播解析和真实流播放尚未实现。不会把提交 URL 伪装为已连接或展示虚构延迟。
- 后续需要接入可用的淘宝直播解析服务及音频播放链路，再验证相对提前量。

## 验证

- JavaScript 语法检查、HTML ID 唯一性、交互目标及本地资源引用检查通过。
- 本地 HTTP 服务返回 200。
- 未进行浏览器交互或视觉测试。
- 可选 WebMCP `stage_taobao_live_link` 仅校验并填入链接，不播放。当前没有支持 WebMCP 的验证上下文，未验证其注册及调用。
